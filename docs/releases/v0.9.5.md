**Aria** joins the Symphony: the existing C01 FP32 FMA workload is now also available as `lab_test(profile: "aria")`, with its exact CPU verification and original 180-second defaults. `c01_test` remains available.

The new `lab_test(profile: "symphony")` runs Aria, then the existing burn, Solo and Leap core movements under one card hold. Each workload keeps its own GPU process and verification; Leap retains its continuous heavy/light transitions. A failed or incomplete movement stops the score. The existing default core profile remains 150 seconds.

Aria now monitors temperature during preparation as well as measurement and stops if temperature readings are unavailable for ten seconds. Lab results require a clean worker exit before reporting a pass, preserve detected errors when a run is interrupted, and distinguish nonfatal CUDA runner errors from fatal device errors. Core-only runs no longer allocate a large memory-test buffer.

A score's aggregate clock and voltage include preparation and multiple movements; they do not establish that a particular V/F point was held. Review the observations for each movement before using a pass as point-specific evidence.

Upgrade with `npx -y clocktail@latest setup` and restart the MCP client.
