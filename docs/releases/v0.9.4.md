Clocktail adds `c01_test` for probing core voltage/frequency stability. The CUDA workload runs sustained FP32 fused multiply-add with 16 accumulators per thread, records intermediate state every eight steps in a hash and checks the GPU result against an independent exact CPU reference.

The tool defaults to 180 seconds and lets you vary the thread-block grid, input seed and temperature stop. It reports observed clocks, voltage, power and power-cap samples alongside its correctness result. The Windows lab executable includes the same workload as `clocktail-lab c01` for GPUs with CUDA compute capability 12.0 or later.

Upgrade with `npx -y clocktail@latest setup` and restart the MCP client.
