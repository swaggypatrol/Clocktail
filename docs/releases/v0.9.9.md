Fixes to the curve tools and the lab, and fewer driver reads in the everyday tools.

`shift_curve` now keeps every point's total offset within the firmware's range when the curve already carries offsets, and reports the points it had to clamp. `adjust_curve` lifts the points to the right of the ones it raised by where the driver actually lands them, so a point on an odd 7.5 MHz half-step is no longer lifted one step too far or too little. `flatten_curve` no longer pushes down a point that only sat high because the driver held it level with a raised neighbour on its left.

`lab_test` waits up to 5 s for the driver-reset event when a run ends in a GPU fault, so the reset is counted instead of being missed. It also stops at the first phase that finds a compute or memory error instead of running the remaining phases. The burn phase no longer pauses the GPU to recompute its reference each time it changes the load to hold the power target. `tune_uncore` ends a comparison after the candidate's first run when the memory phase's core clock falls more than 15 % (the MSVDD cliff), puts the incumbent back and goes on to the next step, saving two runs each time. `game_test` checks steps shorter than a second several times within each step.

`limiter`, `gpu_status`, `card_report` and the live watch take fewer separate driver reads, and `card_report` checks for a newer version while it reads the card. Parsing the frame capture, the residency log and the V/F history allocates less, and the `c01_test` CPU check runs eight classes at once where the processor supports it.

1,669 .NET tests pass, with the GPU and the driver simulated. These changes were not run on a card before this release.

Upgrade with `npx -y clocktail@latest setup` and restart the MCP client.
